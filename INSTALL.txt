RON FACE v0.1.16 - CUTE TAP REACTION
====================================

This is a cumulative update built on the compatible v0.1.15 display package.
It keeps the current face, AI, voice and reminder architecture intact.

INSTALL
-------
1. Stop Ron if he is running.
2. Extract this ZIP directly into:
   C:\Development\Fun-Projects\RonPersonal
3. Allow Windows to merge folders and replace matching files.
4. Activate Ron's virtual environment.
5. Confirm Python starts correctly:

   python -m ron

   Press Ctrl+C after the check.

6. Connect and unlock the Nexus 7 with USB debugging enabled.
7. Install the Android update:

   powershell -ExecutionPolicy Bypass -File .\scripts\install_tablet_face.ps1

8. Start Ron normally:

   python -m ron

NEW TAP BEHAVIOUR
-----------------
- Short taps on the face trigger an immediate, gentle reaction.
- Ron moves away from the touched side, softly squishes, scrunches the nearer
  eye, makes a tiny surprised mouth and rebounds smoothly.
- The movement is intentionally a cute tap response rather than a punch.
- Tapping Ron while he is normally sleeping wakes him with a startled bounce
  and a smooth eyelid-opening transition.
- The visual animation always starts locally on the tablet with no USB delay.
- A best-effort USB signal keeps the laptop's future face snapshot awake too.

SAFETY AND RELIABILITY
----------------------
- Long presses and finger drags do not trigger the reaction.
- Rapid repeat taps are debounced so animations cannot pile up.
- Tap movement uses separate channels and cannot damage blink, speech or mood
  animation state.
- New expressions safely cancel and reset an unfinished tap reaction.
- The navigation arrow remains above the touch surface and never taps Ron.
- Critical-battery or thermal protective sleep cannot be overridden by touch;
  Ron gives only a tiny sleepy response in that safety state.
- If USB is unavailable, the local reaction still works normally.

This overlay does not replace face.py, app.py, voice, wake-word, chat, agent,
memory, reminder or configuration files.
