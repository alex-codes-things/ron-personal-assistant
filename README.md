# Ron

Ron is an open-source personal assistant built from scratch in Python.

The project is currently in early development.

## Goals

Ron is intended to become a fast, private and extensible personal assistant capable of:

- Responding to voice and text commands
- Performing local computer actions
- Managing useful skills and routines
- Remembering information safely
- Integrating AI features where appropriate

## Requirements

- Python 3.12
- Git

## Development setup

Create and activate the virtual environment:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
```
